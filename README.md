# 🧵 SRGM Textiles Website

A modern, responsive textile business website built using **HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB**. The website is designed to provide a professional online presence for a textile company, showcasing its products, company information, and contact details while ensuring a seamless experience across desktop and mobile devices.

---

## 📌 Features

- 🏠 Responsive Home Page
- 📞 Top Contact Information Bar
- 🧭 Sticky Navigation Bar
- 🖼️ Hero Carousel Section
- 🏢 About Company Section
- 🧵 Product Range Showcase
- 📱 Mobile-Friendly Design
- 📍 Contact Information
- 🌐 Social Media Links
- 🎨 Brown & Beige Professional Theme
- ⚡ Fast and Lightweight UI

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/SRGM-Textiles.git
```

### Navigate to the Project

```bash
cd SRGM-Textiles
```

### Install Dependencies

```bash
npm install
```

### Start Backend Server

```bash
npm start
```

or

```bash
node server.js
```
