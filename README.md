# Textile Company Project (SRGM)

A full-stack web application for a textile company, featuring a professional frontend catalog, an enquiry system, and a robust admin dashboard for business management.

## 🚀 Features

### Frontend (Customer Facing)
- **Product Catalog**: Browse textile products with detailed views.
- **Enquiry System**: Customers can send enquiries directly to the company.
- **Quality Assurance**: Dedicated section for quality standards and MSME recognition.
- **Responsive Design**: Modern, mobile-friendly UI built with React and Vanilla CSS.

### Admin Portal
- **Secure Authentication**: Supports both manual login and Google OAuth.
- **Analytics Dashboard**: Visualized business metrics using Recharts.
- **Enquiry Management**: View, filter, and manage customer enquiries.
- **Product Management**: Add and manage product listings.

## 🛠️ Tech Stack

### Frontend
- **Framework**: React.js (Vite)
- **Routing**: React Router DOM
- **Authentication**: Google OAuth (@react-oauth/google)
- **State Management**: React Context API
- **Charts**: Recharts
- **HTTP Client**: Axios

### Backend
- **Server**: Node.js & Express
- **Database**: MongoDB (Mongoose)
- **File Storage**: Mega.js (Integration with MEGA for images)
- **Authentication**: JWT (JSON Web Tokens)
- **Email**: NodeMailer
- **File Uploads**: Multer
